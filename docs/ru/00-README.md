# Документация Polskie Ślady Taszkent

Справочник по коду для разработчиков: что делает каждый модуль, с чем он связан и как им
пользоваться. Английская версия — [`docs/en`](../en/00-README.md), содержание и примеры совпадают.

Правила для ИИ-агента (`CLAUDE.md`, `harness/`, `.claude/rules/`) — отдельная сущность. Эта
документация их не заменяет и не требует работы с агентом.

## Соглашения документации

- Пути даны от `src/`, если не указано иное: `services/navigation.js` = `src/services/navigation.js`.
- Импорты в примерах идут через алиас `@` → `src/`, как в коде.
- Файлы пронумерованы в порядке чтения: `00-README.md` — оглавление, дальше по таблице выше.
  Новая страница встаёт на своё место в этом порядке.
- Документация описывает код в текущем состоянии. Изменили модуль — обновите его раздел
  в `docs/ru` и `docs/en` в том же изменении. Тест `src/docsParity.test.js` проверяет, что обе
  версии содержат одинаковые файлы, одинаковую структуру заголовков и одинаковый код в примерах.
