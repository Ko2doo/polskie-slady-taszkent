# Agent instructions

This project's rules for AI coding agents live in [`CLAUDE.md`](CLAUDE.md) and the
[`harness/`](harness/) files it imports. Read `CLAUDE.md` first, then every `harness/*.md`
file listed in it — they are the project's real engineering rules (architecture, code style,
testing and non-regression, i18n, dependencies, git workflow) and apply to every agent and
every human contributor alike.

This file is only a pointer for agents that look for `AGENTS.md`; don't add rules here —
they go into `CLAUDE.md`/`harness/` so there is one source of truth.
